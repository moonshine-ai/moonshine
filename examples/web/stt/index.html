No microphone? Other ways to try it
Microphone

Browsers keep their own default input, which can disagree with the one your operating system is using, and when it does it returns silence rather than an error. Naming the device here fixes that, and the choice is remembered. The microphone diagnostic shows what each layer is actually producing if this is still not working.
